# 记录自己每天（Android）

当前源码版本：`1.5.0`

完全离线的个人习惯与日程记录应用，可按日期勾选固定习惯、添加日程、填写每日小结，并在日历中回看完成情况。

## 主要功能

- 自定义类别和固定习惯。
- 启用的固定习惯每天出现在今日页面，只有完成后才进入对应日期的日历记录。
- 未完成日程会从创建日起跨日延续，完成当天划线并归档，次日不再显示；取消完成后恢复为持续待办。
- 固定习惯和日程都支持上下拖动，并跨日期持久保存全局顺序；长按拖动时卡片会浮起、跟随手指，相邻内容通过弹簧动画平滑让位，松手后一次性保存顺序。
- 日历按周一至周日严格七列显示，只标记当天实际完成的固定习惯和日程。
- Excel 备份、编辑后合并导入；日程表使用“创建日期、标题、已完成、完成日期、备注、排序”六列，并兼容旧五列模板。
- 本地提醒，无需账号，记录数据保存在手机本机。
- 主页按次记录学习时长和饮水量，并自动汇总当天数据。
- 主页记录起床、睡觉时间，并自动计算跨午夜睡眠时长。
- 每日步数优先读取 Android 健康连接；设备不支持或未授权时可手动记录。
- Excel 备份包含学习、饮水、作息和步数数据，旧版备份仍可导入。

## 构建

1. 使用 Android Studio 打开本目录。
2. 安装 Android SDK Platform 35 和 Build Tools 35.0.0。
3. 使用 Android Studio 的 **Build APK(s)**，或在已安装 Gradle 8.11.1 的环境中执行 `gradle assembleDebug`。
4. 调试 APK 生成于 `app/build/outputs/apk/debug/app-debug.apk`。

`local.properties`、构建缓存和 APK 不保存到 Git 仓库。
